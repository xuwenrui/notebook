1. 下载 Ubuntu 镜像. 官网：https://ubuntu.com/download/desktop
2. 使用[BalenaEtcher](https://www.balena.io/etcher/?spm=a2ty_o01.29997173.0.0.5c755171KGv6QQ)制作U盘启动
3. 按F12使用U盘启动。如果不行，按F1 进入BIOS，在startup>boot中设置U盘启动顺序
4. Try or Install Ubuntu
5. 安装完成拔掉U盘使用安装盘启动，没问题，在startup>boot调整安装盘为默认引导（我的笔记本默认为window boot manager始终会加载windows
6. 多硬盘的化格式化硬盘，挂载硬盘
