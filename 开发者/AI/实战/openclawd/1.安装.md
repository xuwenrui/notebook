npm install pnpm -g
pnpm -v
pnpm config set registry https://registry.npmmirror.com/
pnpm config get registry

修改文件权限
sudo chown -R frank:frank /home/frank/.local/share/pnpm
chmod -R u+w /home/frank/.local/share/pnpm
- `-R` 表示递归修改所有子文件和目录

验证权限
ls -ld /home/frank/.local/share/pnpm/global/bin
