## AI大模型学习计划

### 学习路线（非传统ML路径）
**核心判断**：跳过RNN/CNN/传统ML，直达Transformer和LLM应用

### Phase 1：建立正确心智模型（2-3周）
**目标**：理解LLM本质，避免玄学
- 核心问题：
  - LLM到底在"记忆"还是"推理"？
  - 为什么Prompt工程有时有效有时无效？
  - 上下文窗口的本质是什么？
  - AI记忆/Prompt是过渡产物吗？
- 实践：
  - 阅读：Anthropic《Constitutional AI》、OpenAI《GPT-4 System Card》
  - 动手：用API调用，观察temperature/top_p影响
  - 思考：记录"反直觉"现象

### Phase 2：理解技术栈全貌（3-4周）
**知识地图**：数据准备 → 预训练 → 微调(SFT/RLHF) → 推理优化 → 应用封装
- 快速过理论：吴恩达《生成式AI》课程（3小时）
- 重点看工程：HuggingFace Transformers、LangChain/LlamaIndex、vLLM
- 关键：不陷入数学公式，先建立"调用链"直觉

### Phase 3：选方向深挖（持续）
三个方向任选其一：
- **方向A - Agent开发**：ReAct框架、工具调用、多轮对话
- **方向B - 模型微调**：LoRA原理、RLHF流程、数据配比
- **方向C - RAG系统**：向量数据库、Embedding、检索策略

### 必学基础（最小必要集）
1. **Transformer架构**（核心）
   - Self-Attention机制
   - Position Embedding
   - 资源：《Attention is All You Need》论文 + Jay Alammar《The Illustrated Transformer》
2. **Token化 & Embedding**
   - 用`tiktoken`库实践
3. **预训练 vs 微调**
   - 理解SFT/RLHF
4. **推理过程**
   - 自回归生成、采样策略
